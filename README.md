# DaoPowerplan

一站式 Windows 电源计划管理工具，轻松切换与定制系统电源方案。

## 功能特性

- **预设电源模式**：平衡、高性能、节能三种系统默认模式，始终置顶且不可删除
- **游戏模式**：针对英特尔 / AMD 处理器优化，将性能拉到最大，释放极致游戏体验
- **办公模式**：平衡性能与功耗，延长笔记本续航，适合日常办公场景
- **自定义电源计划**：类似 PowerSettingsExplorer 的详细电源设置编辑，可调节处理器、显卡、硬盘、USB 等各项参数
- **防重复创建**：选择预设模式时，已创建则自动切换，不会重复生成
- **单实例运行**：内置互斥体，防止程序多开

## 系统要求

- Windows 10 / Windows 11（64 位）
- 管理员权限（修改电源计划需要）

## 使用方式

1. 下载 `DaoPowerplan.exe`
2. 右键以管理员身份运行
3. 在主界面选择需要的电源模式，或创建自定义计划
4. 点击应用即可切换

## 预设模式说明

| 模式 | 适用场景 | 特点 |
|------|----------|------|
| 平衡 | 日常使用 | 系统默认，自动平衡性能与功耗 |
| 高性能 | 游戏、渲染 | 处理器始终运行在最高频率 |
| 节能 | 笔记本续航 | 降低处理器性能，延长电池使用时间 |
| 游戏模式（Intel） | 英特尔平台游戏 | 异类线程调度优化、处理器性能最大化 |
| 游戏模式（AMD） | AMD 平台游戏 | 针对 AMD 架构优化、核心性能全开 |
| 办公模式（Intel） | 英特尔平台办公 | 平衡性能、节能设置、延长续航 |
| 办公模式（AMD） | AMD 平台办公 | 针对 AMD 架构的平衡节能方案 |
